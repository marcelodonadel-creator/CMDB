** projeto de banco de dados de um sisitema de vendas ** 

este projeto foi desenvolvido para profução de um banco de dados racional
aplicado a um sistema de vendas

a primeira parte do projeto contem a representação do modelo do DB atravez de
um diagrama de identidade e relacionamento

criação das tabelas:
  - CLIENTES;
  - PRODUTOS
  - PEDIDOS;
  - FORNECEDORES;
  - COMPRAS

  o projeto possui um código fonte revizado e documentado
